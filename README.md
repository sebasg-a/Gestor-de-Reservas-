# Gestor de Reservas

Backend en Spring Boot para gestionar reservas de recursos con validación de solapamientos, cancelación y consulta de disponibilidad por día.

## Stack
- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 (dev)
- Maven

## Ejecutar el backend
Desde `backend/booking`:

```powershell
.\mvnw.cmd clean spring-boot:run
